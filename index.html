              03
              
Supabase 연동

              
    
                
  • 현재 저장 방식에서는 비활성화
    • 
                
  • 운영 로그 저장은 Google Sheets 기준으로 진행

  • URL, key 등 설정값은 화면에 표시하지 않음
    • 
              

            

            

              04
              
Google Sheets 연동

              
    
                
  • 토출 로그 시트 링크 표시

  • 시트 바로 열기 및 링크 복사 제공

  • 관리자 콘솔에서 화면 로그 확인
    •

  • 토출 완료 응답 코드와 오류 코드 정의 필요
    • 
                
  • 실제 자판기 1대 테스트 필요
    •
