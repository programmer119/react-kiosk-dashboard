              01
              
선택별 추천 변경

  • 토출 대상도 현재 추천값 기준으로 변경

토출 플로우

    • 
                
  • 토출 완료 상태 체크
    • 
                
  • 로그 저장 단계 표시
    • 
              

            

            

              03
              
Supabase 연동

              
    
                
  • URL, anon key, table 설정 입력
    •

    • 
                
  • 성공/실패 결과 운영자 로그에 표시
